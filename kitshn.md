# KitSHn Recipe

This repository deploys [Dozzle](https://dozzle.dev/) to the VPS through KitSHn.

## Deployment

- Pushes to `main` deploy `prod`.
- The container listens only on `127.0.0.1:8081`.
- Caddy exposes `https://dozzle.yarden-zamir.com` and protects it with HTTP basic auth.
- `/var/run/docker.sock` is mounted read-only. Dozzle actions and shell access are not enabled.
- Dozzle persistent data is stored under `${KITSHN_DATA_DIR}` on the VPS and mounted to `/data`.

## Required GitHub Configuration

- `vars.KITSHN_VPS_HOST`: SSH target for the VPS.
- `secrets.KITSHN_SSH_KEY`: deploy SSH private key generated by `kitshn recipe auth`.
- `vars.KITSHN_DOZZLE_AUTH_USERNAME`: Caddy basic-auth username.
- `secrets.KITSHN_DOZZLE_AUTH_PASSWORD_HASH`: bcrypt hash generated by `caddy hash-password`, with every `$` escaped as `$$` so Docker Compose can parse `params.env` safely.
